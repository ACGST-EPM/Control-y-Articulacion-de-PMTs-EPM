¿Qué hace esta herramienta? Elimina la escritura manual del campo Descripción del KMZ. El usuario dibuja o importa la geometría y elige los datos en menús validados; la herramienta arma el texto con el formato exacto que exige el motor de análisis y descarga un .kmz listo para la carpeta de entrada.
1Base de datos maestra (la administra el gestor de la plataforma)

Aquí se registran una sola vez los valores que deben repetirse idénticos: contrato → contratista y proyecto. Un contrato puede tener varios municipios (sepáralos con ;): al crear cada trazado se elige el municipio de un menú. El usuario nunca los escribe: los selecciona. 🔒 La edición está protegida con clave de administrador EPM para mantener uniformidad (p. ej. un mismo contratista en varios contratos debe escribirse igual). Guarda el JSON exportado como contratos_db.json en el repositorio para conservarlo.
